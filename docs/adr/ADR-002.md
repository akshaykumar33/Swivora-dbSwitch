# ADR-002: Abstract Syntax Tree (AST) Compiler Pipeline vs. Direct Query String Generation

## Context & Problem Statement

MorphDB translates developer query expressions into queries for heterogeneous databases (PostgreSQL SQL parameterized strings vs. MongoDB BSON Aggregation Pipelines). We must decide how queries are represented internally before execution.

---

## Technical Options Evaluated

### Option 1: Direct SQL / Driver String Generation (Knex-style String Builders)
The query builder directly concatenates strings as API methods are called.
- *Pros*: Simple initial implementation; low memory allocation overhead.
- *Cons*: Highly vulnerable to injection bugs; impossible to optimize queries cross-paradigm; cannot compile a single builder query into a MongoDB Aggregation Pipeline.

### Option 2: Intermediate Abstract Syntax Tree (AST) Compiler Pipeline (Selected)
The query builder generates an immutable intermediate representation (AST nodes). Target database adapters act as visitor compilers that lower the AST into native engine query structures.
- *Pros*: Security against injection; enables query optimization passes (predicate pushdown); supports multi-target translation (SQL vs MongoDB BSON); allows security plugins to rewrite AST trees.
- *Cons*: Memory allocations for AST node objects; microsecond visitor traversal overhead.

---

## Decision Outcome

**Selected Option**: **Option 2 (AST Compiler Pipeline)**.

---

## Rationale & Tradeoffs Analysis

### Why Compiler AST?
1. **Universal Translation**: An AST `SelectQueryNode` with a `FilterExpressionNode` can be lowering-translated to `SELECT * FROM users WHERE status = $1` for PostgreSQL AND `db.users.aggregate([{ $match: { status: 'ACTIVE' } }])` for MongoDB cleanly.
2. **Visitor Type Safety**: TypeScript forces AST visitor compilers to handle all node kinds explicitly.

### Tradeoffs
Slight microsecond AST building overhead, mitigated by compilation result LRU caches.

### Future Scalability
Supports future translation target compilers such as Neo4j Cypher, Redis Command Arrays, and GraphQL query strings.
